fancyqlone::LinearOCPStorage Struct Reference
Optimal control problem formulations

#include <fancyqlone/ocp.hpp>

Detailed Description

Storage for a linear-quadratic OCP of the form.

ₙ₋₁
minimize ∑ [½ uᵢᵀ Rᵢ uᵢ + uᵢᵀ S xᵢ + ½ xᵢᵀ Qᵢ xᵢ + rᵢᵀuᵢ + qᵢᵀxᵢ] + ½ xₙᵀ Qₙ xₙ + qₙᵀ xₙ
ⁱ⁼⁰
s.t. x₀ = b₀
xᵢ₊₁ = Aᵢ xᵢ + Bᵢ uᵢ + bᵢ₊₁
lᵢ ≤ Cᵢ xᵢ + Dᵢ uᵢ ≤ uᵢ
lₙ ≤ Cₙ xₙ ≤ uₙ
