9/// Defines how to solve the small linear system that remains after cyclic reduction.
10/// @ingroup topic-block-tridiag-solvers
11enum class SolveMethod {
12 /// Preconditioned Conjugate Gradient with staircase preconditioner (iterative).
13 StairPCG,
14 /// Preconditioned Conjugate Gradient with Jacobi preconditioner (iterative).
15 JacobiPCG,
16 /// Parallel Cyclic Reduction (direct).
17 PCR,
18 /// The final Schur complement is not solved, so it should be handled manually by the user.
19 /// This is useful when Tricyqle is used to solve a block of a larger system and additional
20 /// coupling to other blocks is present.
21 None,
22};

24inline const char *enum_name(SolveMethod s) {

66/// Parameters and settings for the Cyqlone solver.
67/// @ingroup topic-ocp-solvers
68template <class T = real_t>
69struct CyqloneParams {
70 using value_type = T;
71
72 /// Whether to eliminate the first control input u(0) in the very first iteration of the
73 /// modified Riccati recursion. When set to true, this matches the derivation in the Cyqlone
74 /// paper @cite pas_cyqlone_2025. When set to false, all stage indices are shifted by n-1, and
75 /// u(0) is elimenated in the last iteration of the modified Riccati recursion instead of the
76 /// first. This means that the remaining Schur complement also corresponds to different
77 /// equations, but this is useful in the case of nonlinear dynamics, where during the
78 /// simulation, it is beneficial to have the u(0) at the beginning of the first window instead
79 /// of at the end. Setting this setting to false leads to more fill-in in the first interval,
80 /// but the structure is otherwise the same. It can be seen as a simple relabeling of all
81 /// variables (shifted by n-1). This additional fill-in in the first interval does not actually
82 /// affect the run time, since it is present in all other intervals anyway.
83 /// @todo Is it necessary to isolate the update of x(N) if eliminate_u0_first=false, similar to
84 // what we do for u(0) when eliminate_u0_first=true?
85 bool eliminate_u0_first = true;
86};
